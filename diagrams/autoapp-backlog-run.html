How a backlog runs

Hub and spoke. The host executor decides order, model, time and verdict; each task is one builder turn on its own model. The run answers the gate for edits, builds and previews of its own application, and brings every other question to the person.

Cut from the drawing for budget: the knowledge log every move is written to, and a builder's own question (intent.ask), which reaches the person the same way. Source: docs/autoapp/intents.md, docs/autoapp/security.md.
