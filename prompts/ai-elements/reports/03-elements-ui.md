# 03 — The AI Elements panel

## What was built

`broapp-ai-elements/ui` exports `BroappChat` (the props `AiChat` takes, plus
`markdown`), `BroappChatView`, `ToolApproval`, `Loader` and the vendored
primitives. `broapp-ai-elements/styles.css` is generated by `bun run build:css`
and committed. New tests: `ai-elements-source` (6), `ai-elements-css` (3),
`ai-elements-view` (11), and one case more in `build.test.ts`.

## Vendored: ai-elements 1.9.0

Its registry has no `response` and no `loader`: the markdown renderer is
`MessageResponse` inside `message.tsx`, and the only spinner is shadcn's. So
the CLI was run for `conversation message prompt-input tool attachments`,
`Response` aliases `MessageResponse`, and `Loader` is ours around `Spinner`.
`bunx ai-elements@latest list` **writes the whole registry** rather than
listing it — 73 files, 26 dependencies — so everything outside the import
closure of those five was deleted, leaving 5 ai-elements files and 15 shadcn
primitives under `src/ui/components/`.

## Dependencies, and the network audit

Pinned exactly: `class-variance-authority` 0.7.1, `clsx` 2.1.1, `cmdk` 1.1.1,
`lucide-react` 1.42.0, `nanoid` 6.0.1, `radix-ui` 1.6.7, `streamdown` 2.6.0,
`tailwind-merge` 3.6.0, `use-stick-to-bottom` 1.1.6; `tailwindcss` and
`@tailwindcss/cli` 4.3.3 as devDependencies. Grepping each `dist` for `fetch(`,
`import(` and `https://`: clean — cva, `clsx`, `cmdk`, `nanoid`, `radix-ui`;
comments only — `tailwind-merge`, `use-stick-to-bottom`. Two need an argument:
`lucide-react`'s `dynamicIconImports.mjs` is 2,000 dynamic imports of siblings,
and `streamdown` has one `lazy(() => import('./highlighted-body-*.js'))` behind
the `code` plugin — named icon imports never reach the first, no plugin is
passed so nothing reaches the second, and the built page contains neither name.
Removed with the rest of the dump: `shiki`, `@streamdown/*`, `motion`,
`@xyflow/react`, `media-chrome`, `@rive-app/react-webgl2`,
`embla-carousel-react`, `react-jsx-parser`, `tokenlens`, `ansi-to-react`, `cn`.

## LOCAL edits

1. **`message.tsx`** — the four plugins are gone (`code` pulls shiki; `mermaid`
   and `math` fetch and evaluate; none can run under `default-src 'none'`), and
   `MessageResponse` forces `disallowedElements={['a','img']}`,
   `unwrapDisallowed`, `skipHtml` and `urlTransform={() => null}` **after** the
   caller's props.
2. **`tool.tsx`** — `CodeBlock` is a local `<pre><code>`; the vendored one
   highlights with shiki. `code-block.tsx` was deleted.
3. **`from "cn"` → `../../lib/utils.ts`** in every shadcn file, with
   `src/ui/lib/utils.ts` written by hand (clsx + tailwind-merge): shadcn's
   files import a package called `cn`, the ai-elements files import
   `@/ui/lib/utils`, and one helper is better than two.

## Answers the prompt asked for

- **streamdown 2.6.0 has neither `allowedLinkPrefixes` nor
  `allowedImagePrefixes`.** The `.d.ts` wins; the four props above replace
  them, and the view test proves it — `**bold**` renders, a link keeps its
  words and loses its href, an image vanishes, `evil.example` is nowhere.
- **`skipHtml` drops raw HTML whole** rather than escaping it, so the test
  asserts neither `<script>` nor `alert(1)` survives: stricter than the
  prompt's wording. Without it streamdown strips `<script>` but renders a
  `<div>` the model wrote — markup from a model reaching the page.
- **streamdown renders under `renderToString`**, with no DOM and no stub.
- **`PromptInputActionAddAttachments` is a dropdown-menu item** and throws
  outside a menu. Replaced with a `PromptInputButton` calling
  `attachments.openFileDialog()`; the chips are `Attachments` / `Attachment`
  in a `PromptInputHeader`. `PromptInputActionAddScreenshot` is not rendered.
- **Sizes**: `styles.css` is 50.0 KiB; the page importing `BroappChat` and the
  stylesheet is **873.6 KiB**, against **223.1 KiB** in prompt 01.

## Decisions I made

- **Two shadcn tokens are renamed.** `--accent` and `--border` already mean the
  brand colour and the hairline in a Broapp application, so shadcn's tokens of
  those names read `--accent-surface` and `--border-color`; mapping them
  straight through would paint every hover state the brand colour.
- **Tailwind's `/*! … */` banner is stripped** by `build-css.ts`: it carries
  `https://tailwindcss.com`, and "no absolute address in the CSS" is easier to
  defend with no exceptions.
- **The nine UI dependencies are root devDependencies too**, as `ai` and
  `@ai-sdk/react` are, so `build.test.ts` resolves them from its fixture the
  way a consumer's project would.
